# Aplikasi Pengelolaan Data Putusan Narkotika

Aplikasi desktop berbasis JavaFX untuk pengelolaan
data putusan pengadilan narkotika.

## Technologies

- Java 21
- JavaFX
- Maven
- JUnit 5

## Data Structures

Aplikasi mengimplementasikan:

- DynamicArray
- CustomStack

## Project Structure

- src/main/java: source code aplikasi
- src/main/resources: resource JavaFX
- src/test/java: unit testing
- data: dataset putusan
- docs: dokumentasi proyek

## Requirements

- JDK 21
- Maven

## Build

mvn clean package

## Run Tests

mvn test

## Dataset

Dataset terdiri dari 50 putusan pengadilan
yang telah diverifikasi.

PDF sumber disimpan pada penyimpanan eksternal
sesuai ketentuan dosen.
